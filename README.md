# 🚀 CareerPilot — Student Career Assistant

CareerPilot is a student-focused career dashboard designed to help students organize their learning journey, track progress, and prepare for future career opportunities.

## 🌟 Features

* 📊 Student career dashboard
* 🧭 Career-focused navigation
* 📚 Learning roadmap section
* 💼 Internship tracker section
* 🎯 Skill analysis section
* 💾 Simple, lightweight frontend

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Git and GitHub
* GitHub Pages

## 🌐 Live Demo

[Open CareerPilot](https://ujjawal058.github.io/CareerPilot/)

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/ujjawal058/CareerPilot.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## 🎯 Project Goal

The goal of CareerPilot is to create a useful starting point for students who want to organize their skills, learning goals, and internship preparation in one place.
